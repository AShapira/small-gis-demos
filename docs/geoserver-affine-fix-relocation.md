# Affine-fix project relocation

GeoServer affine-raster fix development now lives in
[AShapira/geoserver-affine-fix](https://github.com/AShapira/geoserver-affine-fix).

The Cesium WMS gutter comparison, Kartoza GeoServer 2.28.0 and 2.28.5 patch
bundles, and supporting affine study, source patches, tests and evidence have
been removed from the `small-gis-demos` source tree starting with release `0.19.0`.
Use the dedicated project for fixes, reproductions, validation and upstream
contributions.

Published tags and Git history are unchanged. The `0.18.0` tag and earlier
relevant tags retain the historical files and their matching licenses and
notices. Consult those versions when working with an old patch bundle.

Existing ignored local evidence, generated archives and caches are retained;
they are not part of the current repository source or future release contents.
